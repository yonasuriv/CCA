# CCA extension capability suite

This suite tests behavior that is claimed beyond the inherited native ICM floor. Cases must require the extension; a task that a competent model can solve by simply leaving unfamiliar folders alone is not discriminative.

Run the same task with pinned ICM, CCA, and no-skill control where meaningful. A CCA extension is demonstrated only when CCA contributes observable correctness, authority preservation, routing quality, intervention reduction, or context efficiency beyond the controls.

Do not mark ICM as failing for a capability it never claims. Record `out-of-scope` where appropriate, while still observing whether it preserves the environment safely.
